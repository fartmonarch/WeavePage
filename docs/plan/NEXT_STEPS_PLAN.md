# WeavePage 后续计划

更新日期：2026-10-21。

本计划补充 [项目蓝图](WEAVE_PAGE_PLAN.md)，以 V0.3 的组件、CSS、使用示例三文件结构为起点。多文件用于交付单个组件，暂不扩展为完整应用生成。

## 1. 已确定的方向

- 主要交付 React + TypeScript + 普通 CSS，优先让用户能复制到自己的项目使用。
- 先支持少量明确的运行环境，后续按需求增加 shadcn 或 Ant Design，不同时兼容所有组件库。
- 不做组件参数调节面板；预览使用默认效果、示例数据和必要回调，支持观察实际交互。
- 预览与用户获得的源码使用同一份组件文件，避免预览能运行、导出却缺少文件或配置。

## 2. 组件参考收录

| 来源                            | 收录内容                                                                           | 优先级                                               |
| ------------------------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------------- |
| Uiverse 普通 CSS 作品、自有示例 | 原始 HTML/CSS、整理后的 React 示例、效果与交互描述                                 | 首批，选择按钮、开关、加载动画、输入框和卡片等小组件 |
| shadcn/ui                       | 组件源码、本地组件与工具依赖、npm 依赖、主题和样式要求；优先利用官方 Registry 数据 | 第二批，先固定一套版本与配置，验证少量组件           |
| Ant Design                      | 官方 API、用法示例、组合方式、包版本和必要配置                                     | 出现后台、表格等业务界面需求时接入                   |
| React Bits 等特效来源           | 效果与实现参考、文件和依赖要求                                                     | 补充来源，按具体许可决定是否收录和复用源码           |

- 每条参考保留来源链接、作者、许可证、采集日期、适用环境和验证状态。
- 许可允许时保留原始代码与适配结果；人工检查 CSS 作用范围和交互，不将自动转换视为验证通过。
- 首批手工精选小量资料，确认结构和检索有效后，再考虑批量采集。

## 3. V0.4：本地参考检索

- 用本地结构化目录管理资料，先做分类、环境等元数据过滤和关键词检索。
- 建立“需求 → 检索参考 → 提供生成上下文 → 返回代码和来源”的流程，页面展示来源与许可证。
- 以组件或完整使用示例组织检索资料；长文档按语义段落拆分，源码按引用关系保留完整文件。
- 保存一组固定需求与预期参考，检查检索相关性及其对生成的实际帮助。
- 数据量或语义召回需求证明简单方案不足后，再评估 Embedding、PostgreSQL / pgvector；暂不预设必须上向量数据库。

## 4. 预览、代码展示与交付

- 页面维持“预览 / 代码 / 接入说明”，代码区支持文件切换与复制，并展示参考来源。
- Sandpack 先使用 React + CSS 模板；扩展组件库时，由项目维护固定版本的依赖、样式、路径别名和必要 Provider。
- shadcn 按源码及其配置装配；Ant Design 按 npm 包接入。工作台的 npm 依赖与预览项目依赖分别管理。
- 初期延续三文件契约；需要更多本地文件时，再扩展文件集合及环境信息，不把所有来源强制压进三个文件。
- 交付包含组件、必需 CSS / 本地工具、使用示例、安装说明和来源许可。纯演示包装与运行必需配置要说明清楚。
- 后续支持下载组件 ZIP 和 README，保证交付文件与预览一致。

## 5. 推进顺序与完成要求

| 阶段         | 主要任务                                                                 | 完成要求                                         |
| ------------ | ------------------------------------------------------------------------ | ------------------------------------------------ |
| V0.4 前整理  | 统一前后端长度上限，补齐本地 bundler 启动说明                            | 限制一致，现有预览可按文档复现                   |
| V0.4         | 精选 React + CSS 参考与检索                                              | 固定案例可重复，来源可追溯，参考实际进入生成流程 |
| 后续环境扩展 | 按需要验证少量 shadcn 组件；Ant Design 按业务需求决定                    | 依赖和配置完整，预览与用户接入均验证通过         |
| V0.5         | 基于当前代码多轮修改、阶段状态与有界修复；按复杂度决定是否采用 LangGraph | 修改保留上下文，失败可解释，修复次数有限         |
| V0.6         | 版本保存、组件导出和固定案例回归                                         | 已保存版本可恢复，导出组件能在消费项目运行       |

Vue 输出、任意 npm 依赖、无限制爬取和完整应用生成继续暂缓。功能状态和验收证据记录在开发文档中，计划只保留目标、边界和决策。
