详细的命令职责、执行目录和依赖安装方法见 [开发命令与依赖管理](development/COMMANDS_AND_DEPENDENCIES.md)。

格式化、lint 和构建的职责不同：Prettier 处理文件格式；ESLint 检查前端代码规则；构建检查工作台的 TypeScript 与打包。`pnpm --filter @weavepage/web lint` 不会添加依赖。

## 前端-- Prettier

> 对ts、.tsx、.json、.css、.md、.yaml等文件进行格式化 受 .prettierignore 排除的文件会跳过。

- pnpm format 自动格式化

- pnpm format:check 只检查格式、不改文件。

## Python 项目-- Ruff

> 都在 apps/api 目录通过 uv 环境进行运行

- uv run ruff check --fix . 检查 Python 代码，并自动修复 Ruff 确认可以安全修复的问题
- uv run ruff check . 检查当前目录下的 Python 代码是否存在 Ruff 能发现的问题，例如 import 顺序、未定义变量等。只检查，不修改文件。
- uv run ruff format . 使用 Ruff 的格式规则，格式化并写回 Python 文件，作用类似 Python 版的 Prettier。
- uv run ruff format --check . 只检查，不修改文件。如果 Python 文件需要格式化，就会列出文件并以失败状态退出。
